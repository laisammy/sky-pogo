# Sky Pogo!
This is an endless 3D jumper game made with Godot 4.6.1. Your goal is to jump as high as you can with the platforms spawning above you!

# Some Key Features
This game saves your high score!!
The disappearing animations are animated!!

# Controls
WASD to move
R to restart the game
